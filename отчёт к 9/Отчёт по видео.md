## Что это за видео?

Это **обучающее видео на русском языке** от канала **CryptoFun [IT]**.  
Автор показывает, как работает **удалённый доступ (RAT)** в **полностью анонимной сети** под названием **Hidden Lake**.  
Это не обычный SSH или TeamViewer — это **анонимный, защищённый и скрытый способ** выполнять команды на удалённой машине, **чтобы никто не узнал**, что вы что-то делаете.

> **Главное**:  
> - Никаких IP-адресов в открытом виде  
> - Никаких прямых соединений  
> - Никаких следов в логах провайдера  
> - Даже «друзья» в сети не могут выполнить команду без пароля

---

## Зачем это нужно?

Представьте ситуации:

- Вы журналист в стране с цензурой  
- У вас сервер в облаке, но вы не хотите, чтобы кто-то видел, что вы им управляете  
- Нужно передать команду на устройство, которое нельзя «светить» в интернете  

**HLR (Hidden Lake Remoter)** — это инструмент для таких случаев.

---

## Как всё устроено? 

### 1. **Сеть Hidden Lake** — это не интернет, а своя сеть
- Работает по принципу **F2F (Friend-to-Friend)**  
  → Вы подключаетесь **только к тем, кому доверяете**  
  → Обмениваетесь **публичными ключами**, как паролями для входа в клуб  
- Все данные идут через **несколько промежуточных узлов (репитеров)**  
  → Минимум **3 штуки**, чтобы никто не понял, кто с кем говорит

### 2. **Кто участвует?**
| Кто | Что делает |
|-----|-----------|
| **Sender (Отправитель)** | Пишет команду и отправляет |
| **Receiver (Получатель)** | Получает, выполняет, возвращает результат |
| **Repeaters (Репитеры)** | Пересылают сообщение, не зная, что внутри |

---

## Как отправить команду?

Допустим, вы хотите создать файл на удалённой машине.

### Шаг 1: Запустить сеть (всё в Docker!)
```bash
docker-compose up
```
→ Запускается 5 контейнеров: Sender, Receiver и 3 репитера.

### Шаг 2: Отправить команду
```bash
curl -X POST http://receiver:8080/remoter \
  -H "Authorization: Bearer мой_секретный_пароль" \
  -d "echo 'Привет, мир!' > /tmp/test.txt"
```

### Что происходит внутри:
```
[Sender] → [Repeater 1] → [Repeater 2] → [Repeater 3] → [Receiver]
```
→ Через 10 секунд приходит ответ: **"OK"**

### Шаг 3: Проверить
```bash
curl -X POST ... -d "cat /tmp/test.txt"
```
→ Ответ: `Привет, мир!`

## Как защищено?

| Защита | Как работает |
|-------|-------------|
| **Анонимность** | Нет прямого IP, данные идут через 3+ узла |
| **Шифрование** | Всё зашифровано ключами (как PGP) |
| **Пароль** | Даже если вы в «друзьях», нужен пароль |
| **Таймаут** | Команда выполняется максимум 5 секунд |
| **Только текст** | Нельзя отправить бинарные файлы (только printable символы) |

> **Brute-force невозможен**: 5 секунд на одну попытку → взлом займёт миллионы лет.

- Создавать/читать файлы  
- Запускать скрипты  
- Проверять состояние системы  
- Получать логи  
- Перезагружать службы (если быстро)

- Интерактивная консоль (как в SSH)  
- Долгие команды (>5 сек)  
- Загрузка/скачивание больших файлов  
- Видео, игры, удалённый рабочий стол

## Как запустить самому? (Пошагово)

1. **Склонировать проект**:
   ```bash
   git clone https://github.com/number571/go-peer.git
   ```

2. **Перейти в папку с RAT**:
   ```bash
   cd go-peer/cmd/hidden_lake/applications/remoter
   ```

3. **Запустить демо**:
   ```bash
   docker-compose up --build
   ```

4. **Дождаться логов** — увидите, как узлы обмениваются ключами.

5. **Отправить тестовую команду** (из контейнера Sender):
   ```bash
   curl -X POST http://receiver:8080/remoter \
     -H "Authorization: Bearer password_from_logs" \
     -d "whoami"
   ```

## Важные предупреждения

- Это **не игрушка** — мощный инструмент  
- Используйте **только в тестовой среде**  
- **Не отключайте репитеры** — потеряете анонимность  
- **Не используйте для нелегального** — автор предупреждает  
- Пароль генерируется автоматически — **сохраните его!**

## Вывод 
**HLR — это как секретный почтальон**:  
Вы пишете записку → отдаёте другу → он передаёт другому → тот третьему → и только тогда она доходит до получателя.  
Никто не знает, от кого и кому.
