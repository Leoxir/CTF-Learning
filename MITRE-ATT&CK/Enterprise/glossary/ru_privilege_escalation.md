# Словарь терминов — Privilege Escalation (русский)

| Английский термин                  | Русский перевод                | Пояснение                                                                 |
|------------------------------------|--------------------------------|---------------------------------------------------------------------------|
| Privilege Escalation               | Повышение привилегий           | Получение более высоких прав доступа, чем изначально предоставлены       |
| Kernel                             | Ядро ОС                        | Центральная часть операционной системы                                   |
| Signed Vulnerable Driver           | Подписанный уязвимый драйвер   | Драйвер с валидной подписью, но содержащий уязвимость                    |
| Bring Your Own Vulnerable Driver   | BYOVD                          | Тактика «принеси свой уязвимый драйвер»                                  |
| CVE                                | CVE                            | Универсальный идентификатор уязвимостей                                  |
| Sandboxing                         | Изоляция в песочнице           | Ограничение выполнения кода в изолированной среде                        |
| Control Flow Integrity (CFI)       | Целостность потока управления  | Защита от перенаправления выполнения кода                                |
| Setuid Binary                      | Setuid-бинарник                | Программа, выполняющаяся с правами владельца (часто root)                |
