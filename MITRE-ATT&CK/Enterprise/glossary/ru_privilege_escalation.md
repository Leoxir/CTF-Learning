# Словарь терминов — Privilege Escalation (русский, обновлено 2025)

| Английский термин                        | Русский перевод                     | Пояснение |
|------------------------------------------|-------------------------------------|----------|
| Privilege Escalation                     | Повышение привилегий                | Получение более высоких прав доступа |
| UAC (User Account Control)               | Контроль учётных записей            | Механизм Windows, запрашивающий подтверждение на повышение прав |
| Bypass UAC                               | Обход UAC                           | Выполнение кода с повышенными правами без диалога подтверждения |
| Setuid / Setgid                          | Setuid / Setgid                     | Биты в Linux/macOS, заставляющие программу работать от имени владельца/группы |
| Sudo caching                             | Кэширование пароля sudo             | После ввода пароля sudo не запрашивает его повторно 15 минут |
| NOPASSWD                                 | Без пароля в sudoers                | Разрешение выполнять команды через sudo без ввода пароля |
| Living-off-the-land binaries (LOLBins)   | LOLBins                             | Легитимные системные утилиты, используемые для атак |
| Accessibility Features                   | Функции специальных возможностей   | Sticky Keys, Utilman и т.д. — заменяются на cmd для получения SYSTEM |
| Baron Samedit                            | CVE-2021-3156                       | Критическая уязвимость в sudo (heap-based buffer overflow) |
| Auto-elevated binaries                   | Автоэлеватные бинарники             | Программы с манифестом autoElevate=true (eventvwr, fodhelper и др.) |
